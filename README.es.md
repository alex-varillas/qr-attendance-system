# Asistia | QR Attendance System

Control de asistencia por QR de código abierto para un solo negocio. Los empleados marcan su asistencia escaneando un código QR (con verificación de ubicación opcional), y el dueño y los supervisores ven el día en un dashboard y exportan reportes.

Versión en inglés: [README.md](README.md)

## Estado

Pre-alfa. El proyecto se está preparando para su primera versión pública. **Todavía no hay código ejecutable en este repositorio**, así que hoy no se puede instalar ni usar nada.

## Funciones previstas

Ninguna está implementada todavía en este repositorio.

- Marcar entrada y salida escaneando un QR, protegido por un PIN personal.
- Verificación de ubicación opcional: el servidor rechaza las marcaciones fuera del radio permitido de una sede.
- Un dashboard con la asistencia del día, las tardanzas y las faltas.
- Empleados, sedes, áreas, horarios y feriados.
- Vacaciones, justificaciones de ausencia y horas extra.
- Estadísticas y reportes en Excel y PDF.
- Roles y permisos para el dueño y los administradores.
- Interfaz en español e inglés.

## Tecnología prevista

- Frontend: React, Vite y Tailwind CSS.
- Backend: Node.js, TypeScript y Fastify.
- Base de datos: PostgreSQL.
- Instalación: Docker Compose.
